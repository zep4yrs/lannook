# LanNook 常见问题（FAQ）

> 面向 v26.3.0。如果你用的是更早版本，部分答案可能不适用。
> 提交问题前请先阅读本文，并搜索 [已有 Issues](https://github.com/by-fengqiao/lannook/issues)。

## 连接

### 手机和电脑连的是同一个 Wi-Fi，为什么还是打不开连接地址？

“同一个 Wi-Fi”不代表设备之间可以互访。依次检查：

1. 不要在手机输入 `localhost` 或 `127.0.0.1`，它们指向手机自身；请使用“连接设备”面板给出的完整地址。
2. 访客 Wi-Fi、校园网、公司网络和开启 AP 隔离的路由器可能禁止设备互访，换到普通家庭网络或电脑热点再试。
3. 关闭手机浏览器的云端加速、VPN、代理或流量节省功能。
4. Windows 网络建议设为“专用网络”；如果诊断显示防火墙规则缺失，可由用户确认后添加规则。
5. 电脑同时连接路由器、热点、VPN 或虚拟网卡时，在连接面板中选择与手机处于同一网络的地址。默认端口是 `53317`。

连接面板的“本机自检”只能确认服务已经监听，不能证明手机到电脑的整条网络路径可达，最终仍要在手机浏览器中验证。

### 为什么有时连接面板里的地址不止一个？

电脑可能同时连接了路由器、热点、VPN 或虚拟网卡。选择与手机处于同一网络的地址即可；不确定时可以逐个尝试。

### 二维码或连接地址可以发给别人吗？

不可以。二维码地址包含配对参数，请不要把二维码或完整连接地址发到不可信的群聊、网页或公共场所。

## 传输

### 传输中断了怎么办？文件会丢失吗？

不会从头开始。LanNook 具备多层恢复能力：

- 文件按 512 KiB 分块上传，单块失败会自动重试并指数退避；
- 网络中断时，上传从已完成分块自动继续（最多自动重试 2 次）；
- 失败的上传/下载任务可以直接点击“继续”，从已完成分块处恢复；
- 重启电脑或本地服务后，进行中的任务会转为可续传状态，支持跨会话续传。

### 怎么确认收到的文件没有被改动？

传输完成后，应用会在后台计算文件的 SHA-256（大文件会实时显示校验进度）。在桌面传输中心可以核对首个文件的完整校验值与短指纹。

需要说明：SHA-256 只是供手工核对的指纹，应用不会自动证明发送端与接收端完全一致；它也不能判断文件是否安全。

### 手机和手机之间可以直接传文件吗？

不能直接 P2P。手机向另一台手机发送时，文件会先进入运行 LanNook 的电脑，再由目标手机接收。

### 传输速度慢怎么办？

- 检查是否开启了下载限速（设置 → 下载限速，`0` 表示不限速）；
- 5 GHz Wi-Fi 通常比 2.4 GHz 更快、更稳定；
- 距离路由器过远、信号弱会显著降低速度；
- 如果同时连接多个网络设备，确认手机连接的是与电脑相同的网络。

## 安全与隐私

### 文件会经过云端吗？

不会。文件直接在局域网内传输，设备记录、授权、传输历史与接收文件都保存在电脑本地（SQLite 数据库），官方发行版不使用公共云文件中转。

### 传输有加密吗？

当前移动连接是局域网明文 HTTP/WebSocket，**没有 TLS 或端到端加密**。请只在你信任且没有陌生用户接入的网络中使用。

### 为什么安装包提示“未知发布者”？

官方发行包默认不进行操作系统级签名，系统可能显示“未知发布者”提示，属正常现象。请只从本仓库的 Release 页面下载。Release 中的 `.sig` 文件是应用更新校验文件，不等同于操作系统代码签名。如需为手工分发的 Windows 安装包补充零成本的 Authenticode 签名，可运行 `scripts/sign-windows.ps1`（见 [docs/signing.md](docs/signing.md)）。

### 别人拿到二维码地址就能连上我的电脑吗？

新设备默认需要电脑端审批。即使有人拿到地址，也会在电脑上弹出接入请求，由你决定是否允许。你可以在设置中关闭审批，但关闭后，拿到有效连接地址的设备可直接接入——不建议在不可信网络这样做。

## 使用

### 手机需要安装 App 吗？需要注册账号吗？

不需要。手机和平板直接使用现代浏览器打开二维码地址即可使用，支持 PWA（iOS/Android 可添加到主屏获得类似 App 的体验），不需要账号。

### PIN 码配对是什么？

无法扫码时，可以在手机连接页输入电脑面板上显示的 6 位 PIN 码完成配对。PIN 码一次性使用、5 分钟有效，连续输错会自动锁定（防暴力破解）。

### 授权时长怎么设置？

- 设备页：新设备接入时选择“仅本次允许”或“信任此设备”，并可指定时长（直到服务关闭 / 1 小时 / 24 小时 / 7 天），到期自动撤销；
- 设置页：可配置默认授权时长。

### 如何升级到新版本？

在“关于”页面检查更新，应用会安装由项目更新密钥签名的新版；也可以从 [Release 页面](https://github.com/by-fengqiao/lannook/releases/latest) 手动下载安装包。

### 支持哪些平台？

- 电脑端：Windows 10/11 x64（`exe`/`msi`）、macOS 10.15+（Apple 芯片与 Intel 的 `dmg`）、Linux x64（`AppImage`/`deb`）；
- 手机端：现代浏览器均可，iOS Safari 与 Android Chrome 体验最佳。

### 怎么导出诊断信息？

在“设置”或“关于”相关入口导出诊断信息（包含版本、日志等），提交 Issue 时一并附上，有助于定位问题。

## 反馈

### 提交问题反馈需要提供什么？

按 [Issue 模板](https://github.com/by-fengqiao/lannook/issues/new/choose) 填写：应用版本、电脑操作系统、手机型号与浏览器、网络环境、复现步骤、实际行为，连接类问题请附上“连接诊断”的输出。
